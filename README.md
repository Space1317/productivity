# 🪐 Планер

Личный планер в одном HTML-файле. Открывается с любого устройства — достаточно перейти на страницу GitHub Pages.

## Возможности

- **Сегодня** — дашборд дня: прогресс по привычкам и задачам, события Google Calendar
- **Задачи** — чекбоксы, добавление/удаление, перестановка, режим 🔒 «лoc задачи — не отметить, пока не выполнены предыдущие»
- **Привычки** — ежедневные привычки, полоса последних 7 дней, SVG-диаграмма выполнения за неделю
- **Календарь** — интеграция с Google Calendar: месячная сетка, просмотр/добавление/удаление событий
- **Заметки** — автосохранение при вводе

Данные хранятся локально в браузере (`localStorage`). Экспорт/импорт JSON — в подвале страницы.

## Использование

Страница открывается напрямую в браузере (двойной клик по `index.html`) или через локальный сервер:

```bash
python -m http.server 8000
# http://localhost:8000
```

## Подключение Google Calendar

1. [console.cloud.google.com/apis/credentials](https://console.cloud.google.com/apis/credentials) → создать проект
2. Включить **Google Calendar API**
3. Создать **OAuth Client ID** типа «Web application»
4. В «Authorized JavaScript origins» добавить свой адрес (например, `https://space1317.github.io/productivity` или `http://localhost:8000`)
5. Вставить Client ID на вкладке «Календарь» приложения → «Подключить Google Календарь»
